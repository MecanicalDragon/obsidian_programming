В любой системе счисления при инкременте, когда разряд упирается в свой максимум, он сбрасывается до нуля, а более старший разряд увеличивается на 1 - фактически, это школьное сложение в столбик:
- `19 + 1 = 20`; `19 + 2 = 21`
- `1001 + 1 = 1010`; `1001 + 11 = 1100`
- `1F + 1 = 20`; `1F + A = 29`

Перевод числа из десятичной системы в любую другую делается через рекурсивное деление числа на основание целевой системы (*base*) с записью остатков до тех пор, пока в результате деления не получится `0`. То есть, последним действием всегда делится число, которое строго меньше основания системы, а затем все записанные остатки просто конкатенируются в обратном порядке: ^ns
- 273 -> 10: `273/10 = 27(3)`; `27/10 = 2(7)`; `2/10 = 0(2)` => `273_10 == 273_10`
- 273 -> 8: `273/8 = 34(1)`; `34/8 = 4(2)`; `4/8 = 0(4)` => `273_10 == 421_8`
- 217 -> 8: `217/8 = 27(1)`; `27/8 = 3(3)`; `3/8 = 0(3)` => `217_10 == 331_8`
- 517 -> 12: `517/12 = 43(1)`; `43/12 = 3(7)` => `517_10 == 371_12`
- 425 -> 12: `419/12 = 35(5)`; `35/12 = 2(11 = B)` =>  `425_10 == 2B5_12`
- 1013 -> 16: `1013/16 = 63(5)`; `63/16 = 3(15 = F)` => `1013_10 == 3F5_16`
- 2024 -> 16: `2024 / 16 = 126(8)`; `126 / 16 = 7(14 = E)` => `2024_10 == 7E8_16`
- 27 -> 2: `27/2 = 13(1)/2 = 6(1)/2 = 3(0)/2 = 1(1)/2 = 0(1)` => `11011`
- 23 -> 2: `23/2 = 11(1)/2 = 5(1)/2 = 2(1)/2 = 1(0)/2 = 0(1)` => `10111`

Стандартный способ свёртывания числа из любой позиционной системы счисления в десятичную - это алгоритм, называемый *горизонтальным сдвигом* (Horner method). Суть в том, что ты идешь слева направо, умножая каждое число на основание системы счисления (base) и прибавляя следующее:
- `273_10` = `(2*10 + 7 = 27) * 10 + 3` = `273_10`
- `421_8` = `(4*8 + 2 = 34_10) * 8 + 1` = `273_10`
- `331_8` = `(3*8 + 3 = 27_10) * 8 + 1` = `217_10`
- `371_12` = `(3*12 + 7 = 43_12) * 12 + 1` = `517_10`
- `2B5_12` = `(2*12 + (B==11) = 35) * 12 + 5` = `425_10`
- `7E8_16` = `(7*16 + (E=14) = 126_10) * 16 + 8` = `2024_10`
- `3F5_16` = `(3*16 + (F=15) = 63_10) * 16 + 5` = `1013_10`
- `11011` = `1*2+1 = 3*2+0 = 6*2+1 = 13*2+1` = `27`
- `10111` = `1*2+0 = 2*2+1 = 5*2+1 = 11*2+1` = `23`

binary, octal, decimal, hexadecimal numeral systems.
